This is a full walkthrough for the Pokémon fangame Pokémon Reborn, using my balance patch. This walkthrough is designed to let you experience the game without hitting any major hurdles that you might during a regular playthrough, and to provide information on all of the key boss fights you will face with the rebalanced teams.

Installation

This patch needs to be installed in a specific way for it to work properly.

  1. Install Pokémon Reborn, version 19.17. (This is the version you get in the updater.)
    THIS MUST BE THE LEGACY VERSION, NOT THE v19.5 VERSION!
  2. Download the All Gen Patch 8.0a and install it over the base game. Download the patch version, not the pre-patched version. Direct link!

    (You can try copying over only the Scripts directory of a newer All-Gen release over the 8.0a maps, for bugfixes, but no guarantees it'll work.)
  3. Download the E19 Music Pack and copy the music files into the BGM directory, as well as the single Ruby file into the Data/Mods directory. Do not copy the other remaining file.
  4. Apply any other mods you wish to use. I have a small list of recommendations below.
  5. Finally, copy my Balance Patch overwriting all files.

If you installed everything correctly, there will be a new NPC inside the starter selection room in the Grand Hall.

Routes

Reborn has a few different story routes which primarily affect events near the end of the game and in the postgame.

This walkthrough will primarily cover the route known as the "Bad" R-Determination path as it's the most complete. At the end of the game, you can switch to the "Good" path very easily without requiring a new save.

You can replay the game entirely to get a different route, e.g. the "Bad" Z-Regular path. That route is only minimally covered.

Relationship Points

This game has a relationship points system, although as far as I can tell it's pretty primitive and doesn't seem to affect many things aside from the true ending cutscenes. I'll mention these occasionally, but won't cover them in depth.

Recommended Mods

Aside from the mandatory mods required for the Balance Patch, there's a few mods that I recommend for the best experience.

  • SWM Modular Modpack  - All mods; I recommend against the starter selection mod as it can make the game too easy or too hard depending on what you pick. Direct download for the *outdated* version that will work with this specific game release!
  • Pyrolusitium Z2   - overhauls the UI significantly. Make sure to install the SWM modpack compatibility file as well.

Hidden Items and Missing Events

This walkthrough will only minimally cover hidden items. Use the item tracker you get in the Slums early.

Likewise, I'll write about most event/static encounters, but I'll skip some that just really aren't worth it. You should be exploring the game as much as possible yourself, anyway!

Left vs Right

Sometimes, you might find that I tell you to go left when you actually have to go right. Sorry! I can't tell left from right. Just go the other way!

Other Useful Resources

  1. The official Reborn spreadsheet contains wild encounters for Pokémon in the original game, the first 100 TM locations, and a basic sticker guide (but I'll cover those too).
  2. The All-Gen patch includes a spreadsheet in your game directory which contains locations for the new Gen 8 and 9 Pokémon, as well as TMs. Nearly all other information is incorrect!!!!! Prefer the information listed in this documentation instead.
